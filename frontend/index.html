LinguaBridge – Viva Project Explanation

Project Abstract & Core Pipeline Summary

"LinguaBridge captures native language speech from a browser microphone, converts it into text via Speech Recognition, applies Natural Language Processing (NLP) text normalization, translates the native text into English using AI Machine Translation, and immediately converts the English text into spoken English voice output using Speech Synthesis."

1. Speech Recognition

Captures audio via Web Speech API, returns recognized native transcript.

➔

2. Language Processing

PythonNLPEngine cleans speech artifacts, filler words (um/uh), expands contractions.

➔

3. AI Translation

Contextual machine translation to natural English via isolated Python backend.

➔

4. English Voice Output

Web Speech Synthesis converts English text to auto-playing spoken audio using Neural Human Voices.

Speech Recognition Module

Utilizes window.SpeechRecognition / webkitSpeechRecognition set to the selected language BCP-47 code (e.g. ja-JP, fr-FR, es-ES, hi-IN).

Python NLP Pre-processing

Dedicated PythonNLPEngine filters hesitation sounds, expands spoken contractions (gonna/wanna), tokenizes text, and provides real-time NLP metadata insights.

AI Machine Translation

Python Flask backend proxies translation requests to secure API endpoints with strict English output validation guard.

Natural Voice Engine

Uses window.speechSynthesis prioritizing high-definition Neural Human Voices (Google US English, Microsoft Jenny Neural) with tuned conversational speed and pitch.
